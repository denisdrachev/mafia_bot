# Mafia Telegram Bot

Телеграм-бот для игры в мафию в групповых чатах: Kotlin 2.3, Spring Boot 3.5, Maven, TelegramBots 10.3
(long polling, **без webhook**), корутины, PostgreSQL + Flyway, метрики Micrometer/Prometheus.

## Возможности

- Сбор желающих в группе по кнопке, запуск игры, статистика игр в группе.
- Настройки на каждую группу (создаются со значениями по умолчанию, меняются командами).
- Роли рассылаются в личные сообщения; голосование, ночные и дневные действия — **эфемерные сообщения** в чате группы
  (Bot API 10.3: `ephemeral_message_parameters`, `editEphemeralMessageText`, `deleteEphemeralMessage`).
- Параллельные независимые игры в разных группах: своя корутина, свой `Mutex` и свой лобби-таймер на чат.
- Результаты игр, роли игроков и события пишутся в базу; ошибки и статистика — в метрики.

## Требования

- JDK 21
- Maven 3.9+
- PostgreSQL 14+ (или профиль `local` с файловой H2)
- Токен бота от @BotFather

## Запуск

```bash
export TELEGRAM_BOT_TOKEN=123456:ABC...        # обязательно
docker compose up -d postgres                  # либо свой Postgres
mvn spring-boot:run
```

Без Docker, на встроенной H2:

```bash
export TELEGRAM_BOT_TOKEN=123456:ABC...
mvn spring-boot:run -Dspring-boot.run.profiles=local
```

Сборка и тесты:

```bash
mvn clean verify
java -jar target/mafia-bot-1.0.0.jar
```

Переменные окружения: `TELEGRAM_BOT_TOKEN`, `TELEGRAM_BOT_USERNAME`, `DB_URL`, `DB_USERNAME`, `DB_PASSWORD`,
`SERVER_PORT`. Токен нигде не хардкодится.

## Команды

| Команда                       | Кто может                        | Что делает                                 |
|-------------------------------|----------------------------------|--------------------------------------------|
| `/help`                       | все                              | список команд                              |
| `/join_game` (или `/gather`)  | все                              | начать сбор желающих (кнопки «Участвую»)   |
| `/start_game`                 | админ группы или инициатор сбора | запустить игру с набранными участниками    |
| `/cancel`                     | админ группы или инициатор сбора | отменить сбор или остановить игру          |
| `/settings`                   | все                              | показать настройки группы                  |
| `/set <параметр> <секунды>`   | админ группы                     | изменить настройку                         |
| `/roles [on\|off РОЛЬ]`       | админ группы                     | список ролей и включение/отключение роли   |
| `/stats`                      | все                              | статистика игр в группе                    |
| `/ef`                         | все                              | отправить эфемерное сообщение (видно только вам) |

Параметры для `/set`: `gather` (30–600), `day` (20–600), `vote` (15–300), `night` (15–300) — секунды.

**Важно:** участник должен нажать Start в личке бота, иначе роль не дойдёт — такой игрок в сбор не попадает.

## Роли

| Роль           | Команда   | Действие                                                                    |
|----------------|-----------|-----------------------------------------------------------------------------|
| `CIVILIAN`     | мирные    | только обсуждение и голосование                                             |
| `COMMISSAR`    | мирные    | ночная проверка: умеет ли игрок убивать                                     |
| `DOCTOR`       | мирные    | ночное лечение (не себя; одного и того же — сколько угодно раз подряд)      |
| `PROSTITUTE`   | мирные    | ночью выдаёт алиби: на следующем голосовании игрока нельзя казнить          |
| `BELIEVER`     | мирные    | днём за 10 сек до голосования усиливает чей-то голос (голос считается за 2) |
| `MAFIA_KILLER` | мафия     | ночной выстрел                                                              |
| `MAFIA_BOSS`   | мафия     | ночью запрещает игроку голосовать на следующем голосовании                  |
| `MANIAC`       | нейтралы  | ночной выстрел, своя победа                                                 |
| `MASOCHIST`    | нейтралы  | побеждает, только если его казнят днём                                      |

Таблица «количество игроков → роли» настраивается в `application.yaml` (`mafia.roles.tables`), лишние места
заполняются мирными. Минимум 3 игрока. Флаг «умеет убивать» (ответ проверки комиссара) переопределяется
через `mafia.roles.can-kill`.

## Ход игры

1. День: обсуждение, дневные действия ролей приватно (эфемерные сообщения).
2. Дневное голосование: у каждого живого игрока своя эфемерная панель без себя в списке; при равенстве
   голосов никого не казнят; лишённые голоса боссом мафии не голосуют; игрок с алиби казни избегает.
3. Ночь: приватные панели выбора цели для ролей с ночным действием; лечение отменяет любые выстрелы в цель;
   два выстрела в одного — одна смерть; отсутствие выбора = действие пропущено.
4. Утро: приветствие и сводка без упоминания исполнителей действий.
5. Повтор, пока не выполнено условие победы.

Условия победы:
- **Мирные** — не осталось живых мафиози и маньяков.
- **Мафия** — живых мирных ≤ живых мафиози и нет живых нейтралов.
- **Маньяки** — живых мирных ≤ живых маньяков и нет живых мафиози.
- **Мазохист** — казнён днём на голосовании (проверяется первым).

## Данные

Flyway-миграция `V1__init.sql`, таблицы: `group_settings`, `group_disabled_role`, `game`, `game_player`,
`game_event`. Незавершённые игры при рестарте помечаются `ABORTED`, чат получает уведомление.

## Метрики

`GET /actuator/prometheus`:

- `mafia_games_started_total`, `mafia_games_finished_total{winner}`, `mafia_games_aborted_total{reason}`
- `mafia_games_active`, `mafia_lobbies_active`, `mafia_lobbies_closed_total{result}`
- `mafia_phase_duration_seconds{phase}`, `mafia_games_duration_seconds{winner}`, `mafia_games_days`
- `mafia_player_actions_total{action}`, `mafia_errors_total{type,exception}`

## Тесты

```bash
mvn test
```

Юнит-тесты игрового движка (распределение ролей, разрешение ночи, подсчёт голосов, условия победы,
валидация настроек) и тест персистентности на H2, проверяющий соответствие Flyway-схемы, JPA-маппингов и
запросов статистики.
